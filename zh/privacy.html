Kraplya

隐私政策

更新于2026年11月5日 · 自2026年10月13日起生效

Kraplya 是一款带计时器的习惯追踪应用。它的设计让你的数据始终属于你：Kraplya 没有自己的服务器，没有自己的账号，没有广告，也没有数据分析。

概览

  • 你输入的所有内容都保存在你的设备上。
  • Kraplya 没有服务器。开发者从不接收也看不到你的数据。
  • 没有广告，没有分析，没有跟踪，不出售数据。
  • Google 云端硬盘同步是可选的，只使用应用自己的隐藏文件夹。
  • 手机日历中的事件只在设备上读取，并且只有在你开启此功能时才会读取。
  • 默认开启：周一小结、日程提醒和更新检查。每一项都可以关闭。

应用保存哪些内容

你自己输入的内容：习惯和分类的名称、目标、已记录的时间、每日的“是/否”标记和带单位的计数、每周日程、奖励和惩罚、个人资料中的名称，以及（如果你添加了）出生日期。出生日期仅用于显示你的统计开始时你多大年纪。

设置：语言、主题、声音、振动和提醒只保存在这台设备上。个人资料名称、出生日期和每周设置（进度条和弹性周）属于你的数据的一部分，会随同步一起传输。

所有这些都保存在你设备上应用的私有存储空间中。其他应用无法读取。Kraplya 已关闭 Android 自带的自动备份，因此 Android 不会自行把应用的数据复制到 Google。

通过 Google 云端硬盘同步（可选）

如果你选择使用 Google 登录，应用只会获得对你 Google 云端硬盘中它自己的隐藏文件夹的访问权限（drive.appdata 权限）。它无法查看、打开或更改你的任何其他文件。登录通过你手机上的 Google Play 服务进行。

你的数据副本会写入该文件夹，这样你的手机和平板显示的内容一致。每台设备写入自己的文件，并读取其他设备的文件。文件包含你的全部习惯、已记录的时间、每日标记和计数、日程、奖励和惩罚、个人资料名称、出生日期、正在运行的计时器，以及已删除项目的空白标记（见“删除你的数据”）。应用还会读取你账号的电子邮件地址，仅用于显示连接的是哪个账号。

每个文件的名称都包含设备的 Android 标识符（a-…，后面是 .kraplya.json.gz）。重新安装后它保持不变，这样手机就能重新找到自己的文件。它只会作为文件名的一部分发送到 Google 云端硬盘。

同步会在你打开应用时运行；开启期间，当手机在线时，后台大约每隔几小时运行一次。数据只在你的设备和 Google 之间通过加密连接传输；开发者无法访问。你可以随时在“个人资料”中关闭同步。这会停止生成新的副本，但不会删除已经在你云端硬盘中的文件。

本应用对从 Google API 获取的信息的使用，遵守 Google API 服务用户数据政策，包括其中的“有限使用”要求。

手机日历（可选）

如果你选择在日程中显示日历事件并允许访问日历，应用会读取你手机上各个日历中的事件（包括已在手机上设置的 Google 日历）：每个事件的标题、时间和颜色。

这些事件只用于在每周日程中显示。事件只在设备上读取：不会保存在应用中，不会包含在备份或 Google 云端硬盘中，也不会发送到任何地方。应用从不更改你的日历。

只有当你自己把某个事件添加到日程中时，它才会进入 Kraplya；此时只保存你确认过的标题和时间。你可以在手机设置中撤销访问权限，或在日程中关闭事件显示。

通知和提醒

通知会显示正在运行的计时器和你的提醒。它们在设备上创建；不会发送到任何地方。

在你允许通知之后默认开启：周一小结（周一 10:00，仅当上周在等待小结时）和日程中时段的提醒。在你开启之前关闭：晚间提醒。你还可以添加自己的提醒。每一项都可以在“个人资料”中关闭。

手机重启后，应用会重新安排提醒。这就是它请求开机启动权限的原因。

更新

在 Google Play 之外分发的 Kraplya 版本会在你打开应用时查找新版本，最多每 30 分钟一次，也会在你点“检查更新”时查找。它会从 Kraplya 网站（pegasohlib.github.io，托管在 GitHub Pages 上）读取一个小文件，当你点“更新”时，从 GitHub 下载新的 APK，并在安装前检查它的 SHA-256。和任何网站一样，它们能看到你设备的 IP 地址；不会发送其他任何内容，也不会发送应用中的任何数据。不会在后台检查。

自动检查默认开启。你可以在“个人资料”中关闭它，仍然可以手动检查。如果应用来自 Google Play，则由 Google Play 负责更新。

GitHub 还会统计每个文件被下载的次数。这只是一个数字，不包含任何关于下载者的信息；网站会把它显示为大致的下载量。

备份和导入

只有当你自己保存备份时，才会在你选择的位置创建备份文件。导入只读取你选择的文件。

该文件是纯文本，没有加密：拿到它的人可以读取其中的所有内容，包括已删除项目的空白标记。Android 的自动备份已关闭，因此这些文件是仅有的备份。

删除你的数据

删除一个习惯、一条记录的计时、一个类别、一项奖励或惩罚，或一个日程时段后，它的内容会立即从设备上移除。只留下一个空白标记：该项目的 ID 和更改的时间。删除一个习惯也会删除它的日程时段。

这些空白标记会进入你的 Google 云端硬盘副本和新的备份文件，这样你的其他设备也会删除该项目。旧版本遗留的数据，会在更新到 0.9.17 后应用首次启动时被清空。之前保存的备份文件，以及另一台设备在更新之前的云端硬盘文件，仍然保留它们原有的内容。

卸载应用会从设备上移除它的数据。它不会移除 Google 云端硬盘中或你保存的备份文件中的任何内容。如果你重新安装并再次开启同步，你的数据会从云端硬盘副本中恢复。

要删除 Google 云端硬盘中的副本，请在“个人资料”中点击“从 Google 云端硬盘删除我的副本”。它会删除本应用在云端硬盘中的文件（涉及你所有的设备），并关闭这台设备上的同步。仍开启着同步的设备会再次上传它的数据，除非你也在那台设备上关闭同步。你也可以在 Google 云端硬盘 → 设置 → 管理应用 → Kraplya → 删除隐藏的应用数据中完成。仅关闭同步会停止生成新的副本，但云端硬盘中已有的副本会保留。
