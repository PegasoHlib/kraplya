Kebijakan privasi

Diperbarui 4 November 2026 · berlaku sejak 13 Oktober 2026

Kraplya adalah pelacak kebiasaan dengan timer. Aplikasi ini dibuat agar datamu tetap milikmu: Kraplya tidak punya server sendiri, akun sendiri, iklan, maupun analitik.

Sekilas

  • Semua yang kamu masukkan disimpan di perangkatmu.
  • Kraplya tidak punya server. Developer tidak pernah menerima atau melihat datamu.
  • Tanpa iklan, tanpa analitik, tanpa pelacakan, tanpa penjualan data.
  • Sinkronisasi Google Drive bersifat opsional dan hanya memakai folder tersembunyi milik aplikasi itu sendiri.
  • Acara kalender ponsel hanya dibaca di perangkat, dan hanya jika kamu mengaktifkannya.
  • Aktif secara default: ringkasan hari Senin, pengingat jadwal, dan pemeriksaan pembaruan. Masing-masing bisa dimatikan.

Apa yang disimpan aplikasi

Yang kamu masukkan sendiri: nama kebiasaan dan kategori, target, waktu yang dicatat, jadwal mingguan, hadiah dan hukuman, nama di profilmu, serta tanggal lahirmu jika kamu menambahkannya. Tanggal lahir hanya dipakai untuk menunjukkan berapa usiamu saat statistikmu dimulai.

Pengaturan: bahasa, tema, suara, getaran, dan pengingat hanya tersimpan di perangkat ini. Nama profil, tanggal lahir, dan pengaturan minggu (bilah dan minggu fleksibel) adalah bagian dari datamu dan ikut disinkronkan.

Semuanya disimpan di penyimpanan pribadi aplikasi di perangkatmu. Aplikasi lain tidak bisa membacanya. Pencadangan otomatis bawaan Android dimatikan untuk Kraplya, jadi Android tidak menyalin data aplikasi ke Google dengan sendirinya.

Sinkronisasi melalui Google Drive (opsional)

Jika kamu memilih masuk dengan Google, aplikasi hanya mendapat akses ke folder tersembunyinya sendiri di Google Drive-mu (izin drive.appdata). Aplikasi tidak bisa melihat, membuka, atau mengubah file lain milikmu. Proses masuk berjalan melalui layanan Google Play di ponselmu.

Salinan datamu ditulis ke folder itu agar ponsel dan tabletmu menampilkan hal yang sama. Setiap perangkat menulis filenya sendiri dan membaca file perangkat lain. Satu file berisi semua kebiasaanmu, waktu yang tercatat, jadwal, hadiah dan hukuman, nama profil, tanggal lahir, timer yang sedang berjalan, dan tanda kosong untuk item yang dihapus (lihat Menghapus datamu). Aplikasi juga membaca alamat email akunmu, hanya untuk menampilkan akun mana yang terhubung.

Nama setiap file memuat pengenal Android perangkat (a-…, lalu .kraplya.json.gz). Pengenal ini tetap sama setelah instal ulang, sehingga ponsel menemukan filenya sendiri lagi. Pengenal ini hanya masuk ke Google Drive, sebagai bagian dari nama file.

Sinkronisasi berjalan saat kamu membuka aplikasi dan, selama aktif, sekitar setiap beberapa jam di latar belakang saat ponsel online. Data hanya berpindah antara perangkatmu dan Google melalui koneksi terenkripsi; pengembang tidak punya akses ke data itu. Kamu bisa mematikan sinkronisasi di Profil kapan saja. Ini menghentikan salinan baru tetapi tidak menghapus file yang sudah ada di Drive-mu.

Penggunaan informasi yang diterima aplikasi dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Kalender ponsel (opsional)

Jika kamu memilih untuk menampilkan acara kalender di jadwal dan mengizinkan akses kalender, aplikasi membaca acara dari kalender di ponselmu (termasuk Google Kalender, jika sudah diatur di sana): judul, waktu, dan warna setiap acara.

Acara tersebut hanya dipakai untuk ditampilkan di jadwal mingguan. Acara hanya dibaca di perangkat: tidak disimpan di aplikasi, tidak dimasukkan ke cadangan atau Google Drive, dan tidak dikirim ke mana pun. Aplikasi tidak pernah mengubah kalendermu.

Sebuah acara masuk ke Kraplya hanya jika kamu sendiri menambahkannya ke jadwal; setelah itu hanya judul dan waktu yang kamu konfirmasi yang disimpan. Kamu bisa mencabut akses di setelan ponsel atau menonaktifkan acara di jadwal.

Notifikasi dan pengingat

Notifikasi menampilkan timer yang sedang berjalan dan pengingatmu. Notifikasi dibuat di perangkat; tidak ada yang dikirim ke mana pun.

Aktif secara default, setelah kamu mengizinkan notifikasi: ringkasan hari Senin (Senin, 10.00, hanya jika minggu lalu menunggu ringkasannya) dan pengingat untuk blok di jadwalmu. Nonaktif sampai kamu mengaktifkannya: pengingat malam. Kamu juga bisa menambahkan pengingat buatanmu sendiri. Masing-masing bisa dimatikan di Profil.

Setelah ponsel dimulai ulang, aplikasi menjadwalkan ulang pengingatnya. Karena itu aplikasi meminta izin untuk berjalan saat perangkat dinyalakan.

Pembaruan

Versi Kraplya yang dibagikan di luar Google Play mencari versi baru saat kamu membuka aplikasi, paling sering setiap 30 menit, dan saat kamu mengetuk Periksa pembaruan. Aplikasi membaca file kecil dari situs web Kraplya (pegasohlib.github.io, di-host di GitHub Pages) dan, saat kamu mengetuk Perbarui, mengunduh APK baru dari GitHub dan memeriksa SHA-256-nya sebelum memasang. Seperti situs web mana pun, keduanya melihat alamat IP perangkatmu; tidak ada yang lain dikirim, dan tidak ada data dari aplikasi. Tidak ada pemeriksaan di latar belakang.

Pemeriksaan otomatis aktif secara default. Kamu bisa mematikannya di Profil dan tetap memeriksa secara manual. Jika aplikasi berasal dari Google Play, Google Play yang memperbaruinya.

GitHub juga menghitung berapa kali setiap file diunduh. Itu hanya angka, tanpa informasi apa pun tentang siapa yang mengunduh; situs web menampilkannya sebagai perkiraan jumlah unduhan.

Cadangan dan impor

File cadangan hanya dibuat saat kamu sendiri menyimpannya, di tempat yang kamu pilih. Impor hanya membaca file yang kamu pilih.

File ini berupa teks biasa dan tidak dienkripsi: siapa pun yang memilikinya bisa membaca semua isinya, termasuk tanda kosong untuk item yang dihapus. Pencadangan otomatis Android nonaktif, jadi file-file ini adalah satu-satunya cadangan yang ada.

Menghapus datamu

Hapus sebuah kebiasaan, sesi tercatat, kategori, hadiah atau hukuman, atau blok jadwal, dan isinya langsung dihapus dari perangkat. Hanya tanda kosong yang tersisa: ID item dan waktu perubahan. Menghapus kebiasaan juga menghapus blok jadwalnya.

Tanda kosong masuk ke salinan Google Drive-mu dan ke file cadangan baru, sehingga perangkat lainmu juga menghapus item itu. Data yang ditinggalkan versi lama dikosongkan saat aplikasi pertama kali dijalankan setelah pembaruan ke 0.9.17. File cadangan yang disimpan sebelumnya, dan file Drive perangkat lain sampai perangkat itu diperbarui, tetap berisi apa yang dulu mereka simpan.

Mencopot aplikasi menghapus datanya dari perangkat. Ini tidak menghapus apa pun dari Google Drive atau dari file cadangan yang kamu simpan. Jika kamu memasang ulang dan mengaktifkan sinkronisasi lagi, datamu kembali dari salinan Drive.

Untuk menghapus salinan dari Google Drive, buka Google Drive → Setelan → Kelola aplikasi → Kraplya → Hapus data aplikasi tersembunyi. Menonaktifkan sinkronisasi di Profil akan menghentikan pembuatan salinan baru.

Anak-anak

Aplikasi ini tidak mengumpulkan data tentang siapa pun, termasuk anak-anak.
