Kraplya

隱私權政策

更新於2026年11月4日 · 自2026年10月13日起生效

Kraplya 是一款附計時器的習慣追蹤應用程式。它的設計讓你的資料始終屬於你：Kraplya 沒有自己的伺服器，沒有自己的帳號，沒有廣告，也沒有數據分析。

概覽

  • 你輸入的所有內容都儲存在你的裝置上。
  • Kraplya 沒有伺服器。開發者從不接收也看不到你的資料。
  • 沒有廣告，沒有分析，沒有追蹤，不販售資料。
  • Google 雲端硬碟同步是選用的，只會使用應用程式自己的隱藏資料夾。
  • 手機日曆中的活動只在裝置上讀取，而且只有在你開啟這項功能時才會讀取。
  • 預設開啟：週一摘要、行程提醒和更新檢查。每一項都可以關閉。

應用程式會儲存哪些內容

你自己輸入的內容：習慣和分類的名稱、目標、已記錄的時間、每日的「是／否」標記和帶單位的計數、每週行程、獎勵和懲罰、個人檔案中的名稱，以及（如果你新增了）出生日期。出生日期僅用於顯示你的統計開始時你多大年紀。

設定：語言、主題、聲音、震動和提醒只儲存在這台裝置上。個人資料名稱、出生日期和每週設定（進度列和彈性週）屬於你的資料的一部分，會隨同步一起傳輸。

所有這些都儲存在你裝置上應用程式的私有儲存空間中。其他應用程式無法讀取。Kraplya 已關閉 Android 內建的自動備份，因此 Android 不會自行把應用程式的資料複製到 Google。

透過 Google 雲端硬碟同步（選用）

如果你選擇使用 Google 登入，應用程式只會取得對你 Google 雲端硬碟中它自己的隱藏資料夾的存取權（drive.appdata 權限）。它無法查看、開啟或變更你的任何其他檔案。登入透過你手機上的 Google Play 服務進行。

你的資料副本會寫入該資料夾，這樣你的手機和平板顯示的內容一致。每台裝置寫入自己的檔案，並讀取其他裝置的檔案。檔案包含你的全部習慣、已記錄的時間、每日標記和計數、行程、獎勵和懲罰、個人檔案名稱、出生日期、正在執行的計時器，以及已刪除項目的空白標記（見「刪除你的資料」）。應用程式還會讀取你帳戶的電子郵件地址，僅用於顯示連接的是哪個帳戶。

每個檔案的名稱都包含裝置的 Android 識別碼（a-…，後面是 .kraplya.json.gz）。重新安裝後它保持不變，這樣手機就能重新找到自己的檔案。它只會作為檔名的一部分傳送到 Google 雲端硬碟。

同步會在你開啟應用程式時執行；開啟期間，當手機在線上時，背景大約每隔幾小時執行一次。資料只在你的裝置和 Google 之間透過加密連線傳輸；開發者無法存取。你可以隨時在「個人資料」中關閉同步。這會停止產生新的副本，但不會刪除已經在你雲端硬碟中的檔案。

本應用程式對從 Google API 取得之資訊的使用，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

手機日曆（選用）

如果你選擇在行程中顯示日曆活動並允許存取日曆，應用程式會讀取你手機上各個日曆中的活動（包括已在手機上設定的 Google 日曆）：每個活動的標題、時間和顏色。

這些活動只用於顯示在每週行程中。活動只在裝置上讀取：不會儲存在應用程式中，不會包含在備份或 Google 雲端硬碟中，也不會傳送到任何地方。應用程式從不變更你的日曆。

只有當你自己把某個活動加入行程時，它才會進入 Kraplya；此時只會儲存你確認過的標題和時間。你可以在手機設定中撤銷存取權限，或在行程中關閉活動顯示。

通知和提醒

通知會顯示正在執行的計時器和你的提醒。它們在裝置上建立；不會傳送到任何地方。

在你允許通知之後預設開啟：週一摘要（週一 10:00，僅當上週在等待摘要時）和行程中時段的提醒。在你開啟之前關閉：晚間提醒。你還可以新增自己的提醒。每一項都可以在「個人資料」中關閉。

手機重新開機後，應用程式會重新安排提醒。這就是它要求開機啟動權限的原因。

更新

在 Google Play 之外散布的 Kraplya 版本會在你開啟應用程式時尋找新版本，最多每 30 分鐘一次，也會在你點「檢查更新」時尋找。它會從 Kraplya 網站（pegasohlib.github.io，代管在 GitHub Pages 上）讀取一個小檔案，當你點「更新」時，從 GitHub 下載新的 APK，並在安裝前檢查它的 SHA-256。和任何網站一樣，它們看得到你裝置的 IP 位址；不會傳送其他任何內容，也不會傳送應用程式中的任何資料。不會在背景檢查。

自動檢查預設為開啟。你可以在「個人資料」中關閉它，仍然可以手動檢查。如果應用程式來自 Google Play，則由 Google Play 負責更新。

GitHub 也會統計每個檔案被下載的次數。這只是一個數字，不包含任何關於下載者的資訊；網站會把它顯示為大致的下載量。

備份和匯入

只有當你自己儲存備份時，才會在你選擇的位置建立備份檔案。匯入只會讀取你選擇的檔案。

該檔案是純文字，沒有加密：拿到它的人可以讀取其中的所有內容，包括已刪除項目的空白標記。Android 的自動備份已關閉，因此這些檔案是僅有的備份。

刪除你的資料

刪除一個習慣、一筆記錄的計時、一個類別、一項獎勵或懲罰，或一個行程時段後，它的內容會立即從裝置上移除。只留下一個空白標記：該項目的 ID 和變更的時間。刪除一個習慣也會刪除它的行程時段。

這些空白標記會進入你的 Google 雲端硬碟副本和新的備份檔案，這樣你的其他裝置也會刪除該項目。舊版本遺留的資料，會在更新到 0.9.17 後應用程式首次啟動時被清空。之前儲存的備份檔案，以及另一台裝置在更新之前的雲端硬碟檔案，仍然保留它們原有的內容。

解除安裝應用程式會從裝置上移除它的資料。它不會移除 Google 雲端硬碟中或你儲存的備份檔案中的任何內容。如果你重新安裝並再次開啟同步，你的資料會從雲端硬碟副本中復原。

要刪除 Google 雲端硬碟中的副本，請在「個人資料」中點一下「從 Google 雲端硬碟刪除我的副本」。它會刪除本應用程式在雲端硬碟中的檔案（涵蓋你所有的裝置），並關閉這台裝置上的同步。仍開啟著同步的裝置會再次上傳它的資料，除非你也在那台裝置上關閉同步。你也可以在 Google 雲端硬碟 → 設定 → 管理應用程式 → Kraplya → 刪除隱藏的應用程式資料中完成。僅關閉同步會停止產生新的副本，但雲端硬碟中已有的副本會保留。
